# IRIX CASH — отчёт по кассе из выписки СберБанка

Приложение из экосистемы **IRIX** (Irina Romanova). Это один HTML-файл `IRIX_CASH.html`. Он берёт PDF-выписку по счёту из СберБанк Онлайн и раскладывает операции по колонкам отчёта по кассе. Дальше приложение сверяет поступления «с топорка» с данными 1С и выгружает отчёт в Excel и PDF для печати.

> IRIX — код. данные. смысл. результат.

---

## Что нужно для работы

- Любой современный браузер: Chrome, Edge, Яндекс.Браузер, Safari, Firefox.
- Интернет. Библиотеки для чтения PDF и создания Excel и PDF подгружаются с CDN.
- PDF-выписка **по платёжному счёту СберБанка**. В СберБанк Онлайн она заказывается в разделе «Выписки и справки». Выписки других банков приложение пока не читает.

Устанавливать ничего не нужно, сервер тоже не нужен.

### Запуск через GitHub Pages

1. Положите `IRIX_CASH.html` в репозиторий. Чтобы страница открывалась по короткой ссылке, назовите его `index.html` или сделайте копию с этим именем.
2. Settings → Pages → Source: *Deploy from a branch*, ветка `main`, папка `/ (root)`.
3. Через минуту приложение будет доступно по адресу `https://<логин>.github.io/<репозиторий>/`.

Выписки и при запуске с GitHub Pages обрабатываются в браузере: на GitHub уходит только сам код страницы, данные туда не попадают. Выписка обрабатывается **только в браузере** и никуда не отправляется.

## Как пользоваться

1. Откройте `IRIX_CASH.html` двойным щелчком. При первом открытии на экране пример с вымышленными данными.
2. Перетащите PDF-выписку в блок «Выписка» или нажмите на него и выберите файл. Можно загрузить несколько выписок сразу, например по разным счетам.
3. Проверьте метку у выписки:
   - **«Сходится с выпиской»**: все операции прочитаны, остаток на начало + пополнения − списания = остаток на конец;
   - **«Расхождение»**: часть операций не прочиталась. Сверьте количество операций с PDF.
4. Просмотрите таблицу «Операции». При необходимости поправьте колонку, комментарий, «Чьё» и отметку «С топорка».
5. Добавьте свои расходы кнопкой **«+ Добавить расход»**, если они не прошли через банк.
6. В блоке «Итоги» введите сумму **«По данным 1С получено с топорка»**. Разница посчитается сразу.
7. Нажмите **«Скачать в Excel»** или **«Печать»**.

Кнопка **«Очистить»** убирает загруженные операции. Правила разноски при этом остаются.

## Колонки отчёта

| Колонка | Что попадает | Знак |
|---|---|---|
| **Лена** | переводы Лене (по правилу «Елена Владиславовна») | минус |
| **Возвраты** | поступления с категорией «Возврат, отмена операции» | плюс |
| **Поступления** | все остальные поступления | плюс |
| **Касса** | снятие наличных в банкомате («Выдача наличных») | минус |
| **Расходы** | все остальные списания | минус |

Ещё в отчёте есть колонки:

- **Комментарий**: короткое название операции по правилам («озон», «касса (снятие наличных)», «мтс связь»). Если ни одно правило не подошло, ставится имя контрагента из выписки («И. Иван Иванович»).
- **Комментарий банка**: категория и описание операции из выписки, без хвоста «Операция по карте ****…».
- **Чьё**: «топ» или «лена».
- **Дата**: дата операции.

## Сверка «получено с топорка»

Блок «Итоги» считает:

```
Всего поступлений по выписке
 − не учтено: <комментарий>   ← поступления без отметки «С топорка», сгруппированы по комментарию
 = Итого получено с топорка
   По данным 1С получено с топорка   ← вводите вручную
   Разница
```

Отметку «С топорка» ставит правило: по умолчанию её получают переводы из **Ozon Bank**. В таблице её можно поставить или снять для любого поступления.

## Ручные операции

Кнопка **«+ Добавить расход»** добавляет строку. Строка подсвечивается зелёным, и в ней можно указать:

- дату (по умолчанию дата последней операции);
- сумму, без знака, знак ставится по колонке;
- колонку, любую из пяти;
- комментарий, описание и «Чьё».

Ручная строка удаляется крестиком справа. В Excel у неё в «Комментарии банка» стоит «добавлено вручную», если описание не заполнено.

Суммы операций из банка изменить нельзя: так проверка с выпиской остаётся честной. Такие строки помечены значком «банк».

## Правила разноски

Блок **«Правила разноски»** внизу страницы раскрывается по клику. Каждое правило:

| Поле | Значение |
|---|---|
| Если в тексте есть | фраза для поиска в категории и описании операции, регистр не важен |
| Комментарий | что записать в колонку «Комментарий» |
| Колонка | «По знаку суммы» (поступление или расход), «Касса» или «Лена» |
| Чьё | «топ» или «лена» |
| С топорка | считать поступление полученным с топорка |

Правила проверяются **сверху вниз**, срабатывает первое подходящее. Если у возврата сработало правило, к комментарию добавляется слово «возврат».

Стандартные правила:

| Фраза | Комментарий | Колонка | С топорка |
|---|---|---|---|
| Елена Владиславовна | лена | Лена | — |
| Ozon Bank | озон | по знаку | да |
| Выдача наличных | касса (снятие наличных) | Касса | — |
| MARKET | яндекс маркет | по знаку | — |
| Сервисы Яндекса | яндекс | по знаку | — |
| KOMISSIYA | моб банк | по знаку | — |
| MTS | мтс связь | по знаку | — |
| Avito | авито | по знаку | — |
| PEREKRESTOK | перекресток | по знаку | — |
| Заработная плата | зарплата | по знаку | — |
| T-Bank | т-банк | по знаку | — |

- **Добавить правило**: новая пустая строка внизу списка.
- **Применить к операциям**: заново разносит загруженные операции по правилам. Ручные правки в строках из банка при этом сбрасываются, ручные операции не трогаются.
- **Вернуть стандартные**: восстанавливает список, приведённый выше.

Правила сохраняются **в этом браузере на этом компьютере** (localStorage). В другом браузере, на другом компьютере или в режиме инкогнито будут стандартные правила.

## Выгрузка

### Excel (`Отчет_по_кассе_<месяц>_<год>.xlsx`)

- Заголовок с периодом, владельцем и счётом.
- Таблица: № · Лена · Возвраты · Поступления · Касса · Расходы · Комментарий · Комментарий банка · Чьё · Дата.
- Строка «Итого» с формулами СУММ. Значения посчитаны заранее, поэтому видны и в просмотрщиках.
- Ниже блок сверки: всего поступлений → не учтено → итого получено с топорка → по данным 1С (жёлтая ячейка) → разница (формула).
- Для печати: альбомный A4, по ширине одной страницы, шапка таблицы повторяется на каждой странице, внизу «Страница N из M».

### Печать (PDF)

Кнопка **«Печать»** собирает PDF: альбомный A4, номера страниц, таблица операций с итогами и блок сверки с 1С. В браузере сразу открывается окно печати. Если всплывающие окна заблокированы, PDF просто скачается, и его можно распечатать.

## Ограничения

- Читаются только **текстовые** PDF-выписки СберБанка по платёжному счёту в текущем формате (колонки «Дата операции / Категория / Сумма / Остаток»). Скан или фото выписки не прочитается.
- Если Сбер поменяет макет выписки, разбор может перестать работать. Об этом скажет метка «Расхождение» или сообщение «Не удалось найти операции».
- Загруженные операции и ручные строки **не сохраняются**: после закрытия вкладки выписку нужно загрузить заново. Сохраняются только правила.

## Для доработки (устройство кода)

Всё лежит в одном файле: стили в `<style>`, логика в одном `<script>` в конце.

**Библиотеки (CDN cdnjs, версии зафиксированы):**

| Библиотека | Версия | Для чего |
|---|---|---|
| pdf.js | 3.11.174 | чтение текста из PDF |
| ExcelJS | 4.4.0 | создание .xlsx с форматированием |
| pdfmake | 0.2.7 (+ vfs_fonts с Roboto, кириллица) | PDF для печати |

**Основные функции:**

| Функция | Что делает |
|---|---|
| `parseSberStatement(pages)` | разбор выписки: строки собираются по координатам текста, операция — строка «дата + время + категория + сумма + остаток», следующая строка — описание. Ещё читает шапку: период, владельца, счёт, остатки, обороты |
| `classify(op)` | применяет правила, возвращает комментарий, колонку, «Чьё» и «С топорка» |
| `bankComment(op)` | «Комментарий банка» без хвоста «Операция по карте…» |
| `calc()` | итоги по колонкам, список «не учтено», итог «с топорка» |
| `buildXlsx()` | формирует Excel |
| `buildPdf()` | описание PDF для pdfmake |
| `saveFile(blob, name)` | сохраняет файл: в claude.ai через `downloads`, локально через обычное скачивание |

**Где менять:**

- стандартные правила: массив `DEFAULT_RULES`;
- набор колонок: объект `COLS` и `colIdx` в `buildXlsx()`;
- цвета и шрифты: переменные в `:root` в начале `<style>`, палитра IRIX (#00E38A, #00B874, #0D1B16);
- ключ хранения правил: `irixcash.rules.v1`.
